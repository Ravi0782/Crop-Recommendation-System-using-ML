⚙️ Full ML Pipeline

Step 01
📥 Data Loading
Read CSV from Google Drive using pandas. Dataset: 2200 rows × 8 columns. No missing values, no duplicates.
Step 02
🔍 EDA
Explored shape, dtypes, value counts, correlation heatmap, and distribution plots (sns.distplot for N).
Step 03
🏷️ Encoding
Mapped 22 string crop labels to integers using crop_dict. Added crop_num column and dropped original label.
Step 04
✂️ Train/Test Split
80/20 split with random_state=42. X: 7 features, y: crop_num target. Train: 1760, Test: 440.
Step 05
📏 MinMaxScaler
Fit on X_train, transform X_train and X_test separately. Scales features to [0,1] range.
Step 06
📐 StandardScaler
Applied after MinMaxScaling. Fit separately on train and test. Standardizes to zero-mean, unit-variance.
Step 07
🤖 Model Training
10 classifiers benchmarked. Random Forest selected as best with 97.95% accuracy.
Step 08
🔮 Prediction
recommendation() function takes N,P,K,temp,humidity,ph,rainfall and returns crop label using saved scaler + RFC.
